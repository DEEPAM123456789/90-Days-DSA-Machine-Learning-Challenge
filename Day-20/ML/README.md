# GPT from Scratch – Bigram Model

## Project Overview

This project is the foundational step towards building a Transformer-based GPT model from scratch. As a warm-up, it implements a **Bigram Language Model** using PyTorch.

## File

- `Build a Bigram Model.ipynb`: Contains code and explanations for the bigram model implementation in a notebook format.

## What’s Implemented

- Tokenization and vocabulary building.
- Bigram probability matrix.
- Sampling predictions based on learned bigram transitions.
- End-to-end training loop for character-level language modeling.
