## Problems Solved:

### 1. [234. Palindrome Linked List](https://leetcode.com/problems/palindrome-linked-list/)
- **Approach**: 
  - Find the midpoint of the list.
  - Reverse the first half of the list.
  - Compare it with the second half to check for palindrome.
- **Time Complexity**: O(n)
- **Space Complexity**: O(1)

---

### 2. [92. Reverse Linked List II](https://leetcode.com/problems/reverse-linked-list-ii/)
- **Approach**: 
  - Traverse to the left boundary.
  - Isolate the sublist between left and right.
  - Reverse it and reconnect with the rest of the list.
- **Time Complexity**: O(n)
- **Space Complexity**: O(1)
