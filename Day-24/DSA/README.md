### 1. [2074. Reverse Nodes in Even Length Groups](https://leetcode.com/problems/reverse-nodes-in-even-length-groups/)
- **Approach**: Traverse the linked list in groups (1, 2, 3, ...) and check group size. If the group has even length, reverse it using a helper function. Carefully manage pointers for linking.
- **Time Complexity**: O(n)
- **Space Complexity**: O(1)

### 2. [3633. Earliest Finish Time for Land and Water Rides I](https://leetcode.com/problems/earliest-finish-time-for-land-and-water-rides-i/)
- **Approach**: Try all combinations of starting with a land ride or a water ride. For each pair, simulate the total journey, considering any required wait times. Track the minimum finish time.
- **Time Complexity**: O(n²)
- **Space Complexity**: O(1)
